# Marketplace (ERP + CRM)

Pet-проект: multi-vendor B2C маркетплейс на микросервисах. ERP и CRM взаимодействуют через события Kafka.

**Стек:** NestJS · TypeScript · PostgreSQL · Prisma · Kafka · Redis · Next.js · Nx · Jest
